# Magic Language Switcher v0.2.0

This release adds six interface languages and a simple light/dark appearance choice while keeping keyboard conversion independent of the interface language.

## Added
- English, Russian, French, German, Spanish, and Italian for settings, correction and clipboard guidance, shortcut recording, tray menus, About, update checks, and download progress.
- Discoverable **Language** and **Theme** dropdowns at the bottom of settings. Choices apply immediately and are retained after restart.
- An isolated developer capture mode for the real settings window, with an explicit locale and theme.

## Improved
- A coherent dark palette for CPU-rasterized panels, text, native inputs, and buttons, including keyboard focus and pressed states.
- Existing conversion layouts, customized shortcuts, Windows startup behavior, and startup update opt-out survive the settings migration.
- Parameterized translations preserve version numbers, shortcut names, transferred sizes, and technical error details. Editor content and installed layout names are not translated.

## Download and upgrade
- Windows 10 version 1607 or newer / Windows 11, x64.
- Portable executable: **MagicLanguageSwitcher-v0.2.0.exe**; SHA-256 is supplied in **SHA256SUMS.txt**.
- Versions v0.1.3 and newer can use **About → Check for updates → Download and install**. v0.1.2 needs a one-time manual download because it recognizes the older asset filename. Existing settings are retained.
- The EXE is unsigned. Native Windows menus and dialogs keep Windows styling; the app settings window uses the selected theme.

## Verification
- Formatting and Clippy with all targets/features pass. Offline tests passed 33 unit checks and one isolated updater handoff/rollback integration check; four desktop/global-shortcut checks are intentionally ignored.
- The optimized Windows x64 executable passes PE/system-DLL checks and packaged icon extraction at 16, 20, 24, 32, 48, 64, 128, and 256 pixels.
- Real English/light and Russian/dark settings captures were inspected at 464 × 555 client pixels (100% scale); both finite capture processes exited successfully.
- A 24.77-second isolated CPU/GDI diagnostic sampled visible, hidden, minimized, and restored idle for approximately five seconds each. Every settled sample recorded no additional paints, rasterizations, or presentations and no measurable process CPU. The background raster was generated once across all transitions.
