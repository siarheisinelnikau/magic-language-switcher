The first public release of **Magic Language Switcher**, a lightweight Windows app written in Rust.

### Download

Run **`MagicLanguageSwitcher-v0.1.0-windows-x64.exe`**. It is a single portable EXE: no installer, .NET, browser engine, or VC++ redistributable is required. Supports Windows 10 version 1607+ and Windows 11 x64.

### Features

- **F8:** fix the last word.
- **Shift+F8:** fix selected text.
- **Ctrl+F8:** undo the last correction after checking that the text still matches.
- Choose any installed Windows keyboard layout in **From** and **To**, or use automatic source selection and next-layout cycling.
- Shift/AltGr character mappings, multiline selections, and clipboard restoration.
- Compact English settings, language shown in the system tray, pause/resume, and optional startup.
- Native About dialog with project link and expandable MIT license.

### Notes

This release is unsigned. Conversion maps direct keyboard output; it does not reconstruct IME candidate selection or multi-key dead-key composition. Unmapped characters stay unchanged. Some editors and elevated apps can block normal copy/paste or simulated input.

Compare the EXE's SHA-256 hash with **`SHA256SUMS.txt`**. See the README for usage, limitations, and build instructions.
