**One correction shortcut and in-app GitHub updates.**

- **About → Check for updates**, also available in the tray menu, checks GitHub Releases on demand.
- **Update and restart** downloads the new EXE, checks its size and SHA-256 against two release sources, replaces it with a backup, and relaunches. Your settings and EXE path stay in place. Keep the app in a writable folder.
- Updates require no installer or extra runtime. Versions before 0.1.2 need this release downloaded manually once.
- **F8** corrects the selected text. If there is no selection, it corrects the last word.
- **Ctrl+F8** remains a separate undo command.
- Both shortcuts are editable in settings. Existing custom last-word and undo bindings are preserved when upgrading.
- The separate selection command and its shortcut are removed.
- Settings now have two shortcut fields and a smaller **464 × 487** logical-pixel window.
- Windows selection APIs distinguish a highlighted range from a caret, including in accessible editors that copy whole lines with no selection.
- Clipboard preservation now handles GDI image formats with the matching Windows APIs.
- A copy failure or a selection with nothing to convert does not trigger an edit elsewhere.

Download **`MagicLanguageSwitcher-v0.1.2-windows-x64.exe`**, a single portable EXE for Windows 10 version 1607+ and Windows 11 x64. No installer, .NET, or VC++ redistributable is required. Checksums are in `SHA256SUMS.txt`.
