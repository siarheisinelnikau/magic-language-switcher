CPU-rendered settings with a retained frame, quicker reopening, and clearer in-app updates.

## Improved

- The settings background is rasterized on the CPU into a retained bitmap. GDI copies only the invalid rectangle; unchanged frames reuse their pixels, and hidden/minimized windows skip presentation. Native Windows controls and text remain intact.
- Reopening settings keeps keyboard tables and layout lists when the installed layouts have not changed. A local 20-command release-build profile reduced the median Open callback round trip from about 17 ms to below 0.1 ms.
- DPI changes apply control bounds and fonts before scheduling a complete repaint. Unchanged control text no longer requests another redraw.
- Shortcut recording saves immediately after key release, without waiting for the polling timer.

## Added

- Nonblocking update checks at startup, enabled by default. **About → Check for updates on startup** is a persistent opt-out; manual checking remains available.
- Startup no-update results and transient errors stay quiet. An available update produces a tray notification, while downloads and installation always require user action.
- **Download and install** displays transferred bytes, percentage, verification, and restart progress in the existing settings window.
- Opt-in diagnostics separate UI callback timing, CPU raster/upload counts, and idle paint requests. The unchanged-window profile reused one rasterization/upload for 21 paints and observed no additional background paints in its visible and hidden idle samples.

## Download and upgrade

Download **`MagicLanguageSwitcher-v0.1.3.exe`**, the single portable EXE for **Windows 10 version 1607+ or Windows 11, x64**. The shorter name is used because this release offers one architecture. `SHA256SUMS.txt` contains its SHA-256 checksum. No installer, .NET, or VC++ redistributable is needed.

**Upgrading from v0.1.2:** its updater recognizes only the old `-windows-x64.exe` asset name. Download v0.1.3 manually once, quit the old app, and replace its EXE at the existing path. Settings remain in `%LOCALAPPDATA%\MagicLanguageSwitcher\settings.conf`. Keeping the old path/name preserves startup entries and shortcuts. v0.1.3 recognizes both filename conventions for future updates. Older releases and their assets remain unchanged.

The automated measurements cover application callbacks and requested repaints, not physical mouse-to-photon latency or all driver/compositor behavior. The CPU/DIB change does not establish that every perceptual lag report is resolved. See [UI performance checks](https://github.com/siarheisinelnikau/magic-language-switcher/blob/v0.1.3/docs/ui-performance.md) for the method and limits.
